# PDF 转换与文献阅读

转换入口：[marker-pdf-to-md](../skills/marker-pdf-to-md/SKILL.md)。使用已配置的本机环境，具体命令、默认参数、输出和验收规则只在该 skill 中维护。

1. **确定本轮问题。** 说明要核实的方法、数据条件、实验结论或近邻差异，不默认每篇都写长摘要。
2. **保存并复用论文。** 新项目使用 `brainstorming/paper/pdf/`、`md/`、`metadata/`。旧项目已有论文库时继续复用，不为每个 idea 复制一份。
3. **转换并验收。** 用 Marker 将 PDF 转为 Markdown，保留同目录图片和 metadata。检查非空和页数，再抽查标题、摘要及本轮关注的表格、公式和图中文字。
4. **记录读取范围。** 写明原始链接/DOI、版本、实际读到的章节与无法确认的内容。摘要阅读不能冒充全文阅读。
5. **把理解写到笔记。** 对具体 idea 的比较与判断写入 `brainstorming/idea_review/<idea-id>/`，不改转换后的论文 MD 来混入 AI 解释。

最小阅读指令：

```text
项目根目录是 /absolute/project。
使用 marker-pdf-to-md 转换……，输出到现有论文库，先检查转换质量。
然后围绕“……”阅读，记录来源位置和实际读取范围，
区分论文事实、我的理解和仍需实验验证的假说。
```

Markdown 中出现缺失、乱码或结构异常时回查 PDF。页数一致只说明基础验收通过，不说明内容逐字完整。扫描页、复杂表格与公式的处理边界见 Marker skill。
